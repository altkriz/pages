What is KrizPages?

KrizPages is a growing collection of hand-crafted web templates. Each template is a single HTML file — no frameworks, no build steps, no dependencies. Just clean code that works.

Every page showcases different techniques in HTML, CSS, and JavaScript. From landing pages to dashboards, from minimal to experimental — the collection keeps growing.
